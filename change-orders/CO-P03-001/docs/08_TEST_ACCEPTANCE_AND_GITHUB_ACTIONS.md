# 测试、GitHub Actions 与 P03 验收

## 多轮对话

- 第一轮声明姓名，后续正确回答；
- “第二种方案”能指向前文；
- 用户纠正事实后旧事实不再生效；
- GPT → Claude → Grok 切换仍保持当前分支上下文；
- Provider continuation 失效时自动本地重建；
- 超过阈值后摘要仍保留金额、日期、决定和约束；
- 不同分支、不同项目、不同用户严格隔离。

## 会话生命周期

- 未发送消息退出，不创建正式会话；
- 第一条消息事务只创建一次；
- 自动临时标题立即出现；
- 最终标题异步替换；
- 手动标题不会被覆盖；
- 首页和抽屉不出现大量“新对话”。

## UI 与普通用户文案

- 新效果图全部逐状态截图比对；
- 首页输入框是首屏主操作；
- 工具入口从输入区 `＋` 打开；
- 模型/回答方式不阻塞开始聊天；
- CONNECTING 只显示“正在思考”；
- 首 Token 后不显示 `streaming`、`connecting` 或生成状态字段；
- 全量扫描普通用户字符串，禁止技术/测试词。

## 分布式就绪

- 两个 AI Runtime 实例交替处理发送和重连；
- SSE 在不同实例按游标恢复且不丢/不重事件；
- 重复提交幂等键不会生成重复消息、运行或扣费；
- 单实例终止后进行中的 Run 能恢复或给出可恢复状态；
- 附件由共享存储读取。
