# 后续全局整合映射

- P04：模型选择、推理强度、多模型对比必须使用同一 Canonical Conversation，不能各自保存孤立上下文。
- P05：图片和文件引用进入 message_parts；后续提到“刚才的 PDF/图片”时可被上下文编译器解析。
- P06：项目指令、项目文件和项目记忆作为独立范围加入上下文，禁止跨项目污染。
- P07/P08：图片和 PPT 任务以工具调用/作品部件写入会话，任务状态进入共享队列。
- P09：用户可控长期记忆、查看/修改/删除、临时对话不写入记忆。
- P10/P11：App 与公共 API 使用相同计量事实，但鉴权、预算和速率限制隔离。
- P12：真正实施多服务器、高可用、压力测试和故障演练。
- P13：官方 API 切换时 Provider continuation 可升级，但 YLVEN 会话事实源不改变。

本包的正式运营与无 Demo 规则对所有后续 Work Packet 持续生效，必须通过脚本写入现有阶段/工作包文档并作为 CI 门禁。
