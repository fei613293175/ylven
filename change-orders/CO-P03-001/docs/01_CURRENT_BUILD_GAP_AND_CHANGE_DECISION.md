# 当前 P03 实现差距与变更决定

## 已确认当前能力

- Android 已能通过业务后端使用 Sub2API 密钥发起模型调用并接收流式回答。
- P03 的会话页面、输入区、首页、会话历史、基础消息存储已存在实现或中间实现。

## 必须在 P03 关闭前修复的问题

### 会话仍为单轮

当前请求只发送本次用户输入，模型看不到同一 `conversation_id` 的历史。模型 API 不会自动知道前一轮内容；YLVEN 必须自己保存并重建上下文。

### 空会话污染历史

点击“新建对话”即创建正式记录，用户未发送内容也会出现多个“新对话”。修正为：第一条有效消息发送前只保存本地草稿，发送时再事务创建正式会话。

### 自动标题没有形成产品闭环

第一条有效消息发送后，客户端立即生成可读临时标题，首轮回答完成后异步优化；用户手动重命名后锁定，不再被自动任务覆盖。

### 首页和会话页是工程说明，不是正式产品

`AI 首页`、`统一多模型对话入口`、`请输入智能推荐`、`生成状态：streaming` 等都属于内部设计或调试语言。正式产品必须使用品牌和普通用户能够理解的文案。

## 变更决定

- 不重做整套开发文档；以 `CO-P03-001` 作为唯一增量变更单。
- 原 P03 工作包完成后追加 W06～W08；P03 不得提前关闭。
- 指定旧页面合同和效果图被本包替代，不允许 Codex同时参考新旧视觉。
- 修正验收后再合并进下一版完整开发计划包，避免永久维护两套事实源。
