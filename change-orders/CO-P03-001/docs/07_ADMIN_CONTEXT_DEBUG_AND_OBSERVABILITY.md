# 管理后台上下文诊断与可观测性

在既有 `YL-M-061 可观测性/AI运行` 中新增 Context Debug 详情抽屉，不新建另一套后台 Shell。

必须展示：

- conversation ID、run ID、用户、模型、路由与时间；
- 模型上下文上限、实际输入、输出预留、推理/工具预留；
- 系统/用户/项目指令、会话状态、摘要、最近消息、附件的 Token 构成；
- 哪些消息被摘要替代、哪些因预算排除及原因；
- Provider continuation 是否使用、是否失败、是否回退本地重建；
- 首字延迟、总耗时、重连次数、实例 ID、事件游标；
- 上下文哈希与版本。

不得展示或保存厂商隐藏思维链。普通运营管理员默认只能查看脱敏内容；查看完整用户内容需要单独权限并写审计日志。
