# 首页与会话体验重构规格

## 品牌表达

- 首页不显示“AI 首页”“统一多模型对话入口”等内部页面描述。
- 首页主文案：`今天想完成什么？`
- 品牌辅助文案：`多模型协同，完成更复杂的事。`
- 用户没有昵称时不要显示邮箱、手机号或数字 UID。

## 首页信息架构

1. 顶部：会话抽屉、YLVEN 品牌、新建草稿入口。
2. 中心：品牌标志、主文案、品牌辅助文案。
3. 主输入框：页面最高视觉权重，直接发送第一条消息；默认模型为“自动选择”。
4. 能力入口：分析文件、生成图片、制作演示只保留紧凑胶囊或放入输入区 `＋` 工具面板，不再使用四张大卡片占据首屏。
5. 最近对话：只显示真实有效且有自动标题的对话；空草稿不进入历史。
6. 底部：原四栏导航保持统一。

## 会话抽屉（YL-A-020）

- 使用模态侧边抽屉，不是独立全屏页面，也不是固定黑色侧栏。
- 抽屉宽度 `304dp`，右侧保留 `56dp` 父页面可见区域。
- 系统状态栏保持全宽；抽屉和遮罩从状态栏下方开始。
- 抽屉右上、右下圆角 `16dp`。
- 父页面必须真实渲染，并覆盖 `#000000 / 32%` 半透明遮罩。
- 点击遮罩、系统返回或向左滑动关闭。
- `YL-A-018` 和 `YL-A-023` 均可作为父页面；效果图以 `YL-A-018` 为审查基准。
- 严禁使用完全不透明、颜色均匀的深色矩形替代遮罩；该问题由 CI 视觉校验直接阻断。

## 会话页

- 不增加“开始新对话”设置页；点击首页输入框或 `＋` 直接进入 `YL-A-023` 草稿状态。
- 模型和回答方式不是强制前置步骤；默认自动，用户需要时从输入区小胶囊打开 Bottom Sheet。
- 顶部标题在第一条消息发送后立即从“新对话”变为临时标题，首轮完成后异步优化。
- 用户消息靠右小气泡；AI 回答全宽，无大卡片包裹正文。
- 首个 Token 前显示“正在思考”及轻量扫光/呼吸效果；首个 Token 到达后直接流式正文，不再展示技术状态。
- 只有真实工具任务才显示“正在阅读文件”“正在生成图片”“正在制作演示文稿”等有意义进度。

## 固定参数

- Android 基准：360×800dp；效果图 1080×2400。
- 普通页面左右边距：16dp；顶部栏 56dp；底部导航 64dp。
- 首页主输入框：最小 100dp，高度可扩展，圆角 24dp。
- 会话输入框：56～148dp，圆角 24dp。
- 用户气泡：最大宽度 84%，圆角 18dp。
- 主文案：28/36sp 700；正文 16/24sp；次级 14/20sp。
- 主色 #5B61F6；背景 #F7F8FC；卡片 #FFFFFF；主文字 #101828；次文字 #475467；边框 #E4E7EC。

所有页面和状态必须按照 `replacements/ui/mockups/` 中的独立效果图实现，不能只读本文件后自行发挥。
