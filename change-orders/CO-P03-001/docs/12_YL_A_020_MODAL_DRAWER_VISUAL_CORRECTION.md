# YL-A-020 会话抽屉视觉修正（R1）

## 修正原因

首版 CO-P03-001 将抽屉右侧区域渲染为完全不透明的深色块，视觉上类似图片黑边，也可能误导实现为固定黑色栏。该渲染不符合模态侧边抽屉的产品语义。

## 最终视觉合同

- 画布：`360 × 800dp`，效果图 `1080 × 2400px @3x`。
- 系统状态栏保持全宽显示；抽屉和遮罩从状态栏下方开始。
- 抽屉宽度：`304dp`。
- 父页面可见宽度：`56dp`。
- 抽屉右上、右下圆角：`16dp`。
- 遮罩：`#000000`，透明度 `32%`。
- 遮罩下必须真实呈现父页面 `YL-A-018` 或 `YL-A-023`。
- 点击遮罩、系统返回键或向左滑动均关闭抽屉。
- 严禁使用完全不透明、纹理单一的固定深色栏替代遮罩。

## 状态范围

全部九个状态已重新设计：加载、有数据、空数据、刷新、搜索结果、离线缓存、网络错误、服务错误、登录失效。每个状态均保留相同抽屉几何和父页面遮罩关系，只改变抽屉内部状态内容。

## Codex 实现要求

使用 Compose `ModalNavigationDrawer` 或等价的可测试组件。不得在页面布局中增加固定宽度黑色 `Box`。运行截图的抽屉外区域必须能够检测到父页面内容变化；CI 执行 `scripts/38_VALIDATE_DRAWER_OVERLAY_VISUALS.py`。
