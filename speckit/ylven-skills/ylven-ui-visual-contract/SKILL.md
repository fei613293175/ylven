# YLVEN UI Visual Contract

1. Read the current work packet.
2. Resolve its Page IDs from `contracts/work-packet-map.yaml`.
3. Read each page contract and `YL-DS-1.2.0` tokens.
4. Run the visual gate before UI implementation.
5. Treat mockups as visual-only and Feature IDs as functional authority.
6. Produce screenshots and a visual diff report for every applicable state.
