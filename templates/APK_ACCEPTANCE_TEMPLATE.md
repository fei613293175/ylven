# APK 真机验收模板

## 1. 安装与升级

1. 记录设备型号、Android 版本、可用存储和网络。
2. 校验 APK SHA-256 与 `SHA256SUMS.txt`。
3. 首次安装验证启动、权限请求和冷启动；有上一阶段 APK 时再验证覆盖升级和数据保留。
4. 测试杀进程、切后台、断网/恢复、屏幕旋转和系统字体放大。

## 2. 当前阶段功能

逐项从 `FEATURES.md` 选择项目所有者可见的功能，记录 Feature ID、操作、实际结果、预期结果和截图。不要仅写“全部正常”。

## 3. UI 与可访问性

检查小屏、长文本、键盘弹出、深/浅色、对比度、最小点击区域、读屏语义、加载/空/错误状态和返回导航。

## 4. 后台体验

检查对应菜单、过滤、详情、配置修改、失败提示、审计记录和回滚入口。配置更新后确认 App 或 API 在预期缓存时间内生效。

## 5. 结论

- P0/P1：阻止阶段批准。
- P2：原则上当前阶段修复，或由项目所有者书面接受紧邻修复。
- P3：记录到精修任务，不得遗忘。
