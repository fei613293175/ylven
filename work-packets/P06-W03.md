## 1. 功能范围

- `P06-011` — 生成向量并保存到 pgvector
- `P06-012` — 基于项目资料执行混合检索
- `P06-013` — 把检索结果编译进模型上下文
- `P06-014` — 在回答中显示项目文件引用
- `P06-015` — 显示知识文件索引状态和失败原因

不在上述 Feature ID 中的功能不得因为效果图、示例文案或模型推测而新增。需要新增功能时，必须先更新 `contracts/feature-map.yaml`、页面合同和效果图绑定。

## 4. 效果图与功能的权威边界

1. 效果图只决定布局、层级、字号、行高、圆角、边距、高度、间隙、色值、组件位置和可见状态。
2. 功能、接口、数据库、权限、计费、异步任务和导航由 Feature ID 与开发文档决定。
3. 效果图中的用户名、金额、模型名、文件名、日期和聊天内容均为虚拟样例，不得写死进产品，也不得据此创造功能。
4. 效果图中出现但没有 `ui-interaction-map.csv` Interaction ID 的控件，只能作为装饰或禁用示意；Codex不得擅自赋予点击行为。
5. 开发文档要求但当前效果图未展示的功能不得被删除；应先提出视觉合同变更并补充效果图。
6. 数值冲突时，`ui-design-tokens.yaml` 和逐页 resolved contract 优先于对图片的肉眼估算；功能冲突时 `feature-map.yaml` 优先于效果图文案。

## 5. 实施顺序

1. 运行 UI 合同规划校验：`.\ylven.ps1 py scripts/19_VALIDATE_UI_CONTRACTS.py --mode planning`。

3. 运行视觉门禁：`.\ylven.ps1 py scripts/20_CHECK_UI_VISUAL_GATE.py --packet P06-W03`。
4. 若门禁未通过，只实施非视觉工作并记录 `BLOCKED_VISUAL`；禁止凭空画页面。
5. 门禁通过后，使用统一组件实现，不得在页面内硬编码新的字号、颜色、圆角或间距。
