## 实现证据

- `0005_p03_canonical_context.sql` 增加规范化分支、严格消息顺序、父消息、比较组、`message_parts`、摘要、上下文构建、模型能力、Provider continuation、持久化任务和压缩记录。
- `ConversationContextCompiler` 按模型能力计算输入预算，短会话保留完整历史，长会话使用可追溯摘要并按完整轮次裁剪；原始消息不因摘要删除。
- 正式 Run 从 PostgreSQL 中的同一 Canonical Conversation 重新编译上下文；Provider continuation 只作为优化，失效后回退本地历史。
- 第一条有效消息在事务中创建正式会话、默认分支、用户消息和 Run；只打开空白草稿不会进入历史。
- 首条有效消息立即产生临时标题，首轮完成后异步优化；手动重命名写入 `title_source=USER`、`title_locked=true`，后续自动任务不能覆盖。
- Android 正式消费者文案把内部运行状态映射为“正在思考”等普通用户语言；验收状态类仅保留在 `androidTest`。
