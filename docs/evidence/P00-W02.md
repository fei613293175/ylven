## Contracts and behavior

- Five process identities expose their feature health path plus `/healthz`, `/readyz`, and `/version`.
- Dependency failures produce deterministic `degraded`/`unready` states and readiness returns HTTP 503.
- Response errors use the OpenAPI `error.code`, `message`, `request_id`, `retryable` envelope shape.
- Worker transitions are `QUEUED -> RUNNING -> SUCCEEDED|FAILED|CANCELLED`; duplicate idempotency keys do not duplicate work, retries are bounded, and exhausted poison jobs enter the failure archive.
- Scheduler locks reject active contention, allow expiry takeover, monotonically increase fencing tokens, reject stale release, and execute a scheduled callback once per held lease.
