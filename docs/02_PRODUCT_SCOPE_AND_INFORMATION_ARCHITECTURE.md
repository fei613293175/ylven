# 02 产品范围与信息架构

## 1. 一级导航

底部导航固定为四项：

1. **首页**：AI 首页、新建对话、历史对话、模型与推理选择、多模态输入、流式回答。
2. **工作**：工具、项目、文件资料库、图片、PPT、作品库、异步任务中心。
3. **发现**：由后台动态配置的服务、模板、工作流、模型实验室、公告和未来连接器。
4. **我的**：个人资料、套餐、钱包、用量、开发者 API、项目/文件/作品快捷入口、安全和设置。

进入具体聊天页面、PPT 编辑页面或图片编辑页面时，可隐藏底部导航以增加内容空间；返回一级页面后恢复。

## 2. 跨模块核心对象

### 2.1 Conversation 会话

- 每个会话由 YLVEN 生成 UUID，不依赖上游厂商会话 ID。
- 会话拥有标题、默认模型、默认推理档位、项目归属、自定义指令、摘要、归档和临时会话设置。
- 每条消息保存实际模型和路由，允许同一会话中切换模型。
- 数据层预留分支、重答和多模型对比，即使首个 UI 版本先以线性方式显示。

### 2.2 Project 项目

项目是长期上下文容器，包含多个会话、项目指令、文件、知识索引、作品和默认模型。项目可以独立设置数据保留、知识检索和模型偏好。

### 2.3 Library 资料库

资料库保存用户上传的原始文件、解析结果、缩略图、版本、权限和生命周期。上游厂商的 file_id 只作为临时引用，不是永久主键。

### 2.4 Artifact 作品

图片、PPT、文档、表格等完整成果必须保存为独立作品，并具备版本历史。作品可以从对话产生，也可以直接从工作页创建。

### 2.5 Job 任务

图片生成、图片编辑、PPT 渲染、文件解析、知识索引、数据导出等长耗时工作统一进入任务中心。任务必须支持排队、运行、进度、成功、失败、取消、重试和死信处理。

### 2.6 Model Capability 模型能力

模型能力来自后台动态模型目录和实际能力探测。App 只展示已验证的能力，不根据厂商网页宣传自行假定当前 Sub2API 通道一定支持。

## 3. 首页主要流程

### 3.1 AI 首页空状态

- 顶部左侧打开会话抽屉；中部展示 YLVEN 或当前项目；右侧新建会话。
- 模型条显示当前模型、推理档位、联网和工具状态。
- 主区域显示问候语、4～6 个高频快捷入口、最近会话和最近项目。
- 底部输入区允许文本、附件、相机、相册、文件和语音输入。

### 3.2 对话流程

1. 用户输入文本或添加附件。
2. 用户可使用会话默认模型，也可为本条消息临时选择模型与推理强度。
3. App 创建 Run，后端完成权限、额度、文件状态和模型能力检查。
4. AI Runtime 通过 SSE 返回结构化事件；App 支持停止、断线续传和后台恢复。
5. 完成后保存最终消息、使用量、价格快照、路由、延迟、引用和作品引用。
6. 用户可复制、朗读、分享、反馈、换模型重答、创建分支或发起多模型比较。

## 4. 工作页主要结构

顶部使用分段标签：`工具 | 项目 | 作品 | 任务`。

- 工具：图片生成、图片编辑、PPT、文件分析、多模型对比，后续可扩展深度研究和数据分析。
- 项目：项目列表、项目详情、项目指令、会话、文件、知识库、作品。
- 作品：按图片、PPT、文档、表格分类，支持收藏、搜索、下载、版本和继续创作。
- 任务：统一查看所有异步任务状态，支持取消、重试和错误详情。

## 5. 发现页

发现页不能只显示“敬请期待”。首期就应由后台配置并展示：

- 模型实验室；
- Prompt 模板；
- AI 使用技巧；
- 推荐工作流；
- 系统公告；
- 即将上线服务；
- 服务状态入口。

每个卡片由后台控制标题、图标、副标题、排序、上线状态、灰度范围、最低 App 版本和跳转类型。

## 6. 我的页面

### 6.1 顶部资料卡

显示头像、用户名、数字 UID、当前套餐和到期状态。点击进入资料编辑。

### 6.2 内容与使用

- 我的项目；
- 我的作品；
- 我的文件；
- 我的收藏；
- 用量中心。

### 6.3 商业与开发者

- 套餐与权益；
- 钱包和充值；
- 账单明细；
- API 与开发者；
- API Key；
- API 预算与告警；
- 模型和价格。

### 6.4 AI 偏好与安全

- 默认模型和推理档位；
- 回答风格；
- 自定义指令；
- 个人记忆；
- 登录设备；
- 生物识别锁；
- 数据导出和注销。

## 7. 首期不包含

- iOS 客户端；
- Google Play 上架和 Play Billing；
- 实时双向语音通话；
- 团队工作区和复杂企业组织；
- 公共插件市场；
- 面向外部用户的订阅代理 API 商业销售；
- 端到端加密导致后台无法进行用户主动发起的内容处理。
