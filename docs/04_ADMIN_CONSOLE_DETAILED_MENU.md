# 04 专业管理后台菜单与功能规格

## 1. 技术与权限

后台使用 Vue 3、TypeScript、Vite、Ant Design Vue、Pinia、Vue Router 和基于 OpenAPI 生成的类型化 API 客户端。管理后台必须独立于 Sub2API 后台；它管理 YLVEN 产品业务，并通过适配器查看或操作 Sub2API 映射数据。

权限采用 RBAC，首期角色至少包含：

- `SUPER_ADMIN`：全部权限；
- `OPERATIONS`：用户、内容、发现、模板、任务；
- `MODEL_OPERATOR`：模型、通道、路由、能力探测；
- `FINANCE`：产品、订单、支付、账本、对账；
- `SUPPORT`：用户、会话元数据、工单，默认不能查看敏感文件内容；
- `AUDITOR`：只读审计和报表；
- `RELEASE_MANAGER`：App 版本、APK、公告、灰度。

敏感操作要求重新验证管理员身份、填写原因，并写入不可变审计日志。

## 2. 菜单树

### 2.1 运营总览

- 实时业务概览；
- 请求量、成功率、首字延迟、完整响应时间；
- 在线流式连接；
- 图片/PPT/文件任务队列；
- 今日收入、充值、扣费和退款；
- 模型与通道健康；
- 当前告警和事故；
- 活跃用户、留存和版本分布。

### 2.2 用户与身份

- 用户列表和高级筛选；
- 用户详情、资料、状态、套餐、余额、用量；
- 邮箱身份、OIDC/Sub2API 映射；
- 登录设备、会话和强制下线；
- 登录验证码和风控事件查询；
- 角色、组织与权限预留；
- 封禁、解封、注销、数据导出；
- 管理员人工调整必须通过账本或权益授予，不直接改字段。

### 2.3 模型与供应商

- 供应商目录；
- 模型目录、展示名称、描述、排序和上下架；
- 能力配置与实际探测结果；
- 推理档位映射；
- 上下文长度、输出限制和超时；
- 模型价格版本；
- 路由通道、优先级、主备和熔断；
- Sub2API 分组和官方 API 通道；
- 灰度、用户白名单和服务状态；
- 一键能力探测及历史报告。

### 2.4 Sub2API 与外部通道

- Sub2API 连接配置和健康检查；
- 用户映射、内部 Key、开发者 Key 映射；
- 余额投影、套餐映射和同步任务；
- 使用记录回流和对账；
- 同步失败、幂等冲突、人工重试；
- 官方 OpenAI、Anthropic、xAI 通道配置；
- 测试/生产环境隔离；
- 密钥轮换和凭据到期提醒。

### 2.5 对话与内容

- 会话列表、状态、项目、模型和用量；
- 消息运行记录、错误、工具调用和引用；
- 用户反馈和模型质量标签；
- 临时会话清理；
- 内容安全事件；
- 默认只展示元数据，查看正文或附件需要独立权限和审计原因。

### 2.6 项目、文件与知识库

- 项目列表、成员预留、项目指令；
- 上传文件、文件版本、解析状态和病毒扫描；
- 知识文档、分块、向量索引和检索测试；
- R2 存储统计、孤儿对象和生命周期；
- 文件删除、恢复和法定保留预留。

### 2.7 图片、PPT 与作品

- 图片生成/编辑任务；
- PPT 项目、生成任务、页面和版本；
- PPT 模板、品牌模板和页面布局；
- 作品列表、版本、素材引用和下载；
- 失败任务、死信任务、取消和重试；
- 队列优先级、Worker 并发和服务状态。

### 2.8 商业化与财务

- 产品、套餐、价格和权益；
- 订阅、升级、续费、到期和取消；
- 订单、支付、退款和回调；
- 钱包账户、额度桶和不可变账本；
- 充值余额、套餐额度、赠送额度；
- AI 用量、价格快照、扣费和补偿；
- Sub2API 余额对账和差异处理；
- 财务报表导出。

### 2.9 开发者平台

- 开发者用户和应用；
- API Key、权限、IP 白名单和模型白名单；
- 账号总预算、单 Key 预算、并发和速率限制；
- 调用日志、错误、延迟、费用和来源；
- Webhook、重试和签名密钥；
- API 版本、文档和 SDK 版本；
- 公共 API 服务状态和事故公告。

### 2.10 发现页与内容运营

- 首页快捷入口；
- 发现页分类、卡片和布局；
- Prompt 模板；
- 工作流模板；
- 模型推荐；
- 公告、活动和帮助中心；
- 灰度用户、最低 App 版本和定时发布。

### 2.11 App 发布

- APK 上传和对象存储；
- 版本号、versionCode、渠道和环境；
- 更新说明、最低支持版本、强制更新；
- 灰度比例、白名单、下载链接和校验和；
- 下载统计、安装反馈预留；
- 版本回滚和下架。

### 2.12 安全与审计

- 管理员账户和角色；
- 操作审计；
- 配置变更历史和回滚；
- 登录风险、验证码滥用和 IP 黑名单；
- API Key 泄漏与异常消费；
- 敏感数据访问记录；
- 密钥和证书到期；
- 安全事件和处置记录。

### 2.13 可观测性与运维

- 服务实例、健康检查和版本；
- 指标、日志和链路追踪；
- 数据库连接、慢查询和锁；
- Redis、NATS、R2 和队列状态；
- 定时任务和死信；
- 告警规则、静默和事故；
- 备份、恢复、PITR 和演练记录；
- 配置中心和 Feature Flag。

## 3. 后台通用交互要求

- 所有列表支持分页、排序、组合筛选、列配置和导出权限。
- 所有配置记录包含草稿/已发布状态、版本号、变更人、变更原因、时间、差异和回滚入口。
- 删除默认采用软删除或状态停用；物理删除必须有专门流程。
- 重要操作必须二次确认，不使用仅写“确定/取消”的模糊弹窗，应说明影响对象和不可逆后果。
- 后台错误必须展示错误码、追踪 ID 和可复制的排查信息，不直接展示堆栈或密钥。
