## 1. 交付物、安装与恢复

- [ ] 对照 `SHA256SUMS.txt` 校验 APK SHA-256。
- [ ] 首次安装、冷启动、杀进程重启、前后台切换、断网恢复、旋转和字体放大均无崩溃或无限加载。
- [ ] 已安装 1.0.0 时覆盖升级到 1.1.0，数据和登录态按预期保留；卸载重装后回到首次使用状态。

## 2. 注册与登录 API（P01-001 至 P01-012）

- [ ] 邮箱规范化、非法格式校验、注册挑战和登录挑战成功；重复/缺参请求返回稳定错误。
- [ ] Turnstile 有效 token 通过；无效、过期、重放 token 拒绝。
- [ ] 注册/登录 OTP 可收到并验证；错误、过期、重放验证码失败，重发有冷却。
- [ ] 注册完成创建用户并安全保存密码；重复邮箱并发请求只创建一个用户。
- [ ] 登录不泄露未知邮箱是否存在；访问令牌和刷新令牌可用，刷新令牌轮换且旧 token 失效。

## 3. 会话、设备、限流与审计（P01-013 至 P01-018）

- [ ] 退出当前设备仅撤销当前会话；退出全部设备撤销所有会话。
- [ ] 设备列表只显示当前用户；撤销指定设备后目标会话失效、其他设备不受影响。
- [ ] 触发认证限流后得到可理解的限流结果，冷却后可恢复。
- [ ] 注册、登录、刷新、退出、设备撤销和风险操作都有审计记录；记录不含密码、OTP 或 token。

## 4. 管理后台设置与用户（P01-019 至 P01-024）

- [ ] 在 YLVEN 管理后台读取/修改邮件、Turnstile、OTP 设置，保存后回读一致；Secret 只引用外部变量且不可回显。
- [ ] `YL-M-027` 用户列表和详情使用真实 API 数据，不展示密码哈希、令牌或不必要敏感字段。
- [ ] 禁用用户立即撤销已有会话并阻止登录；恢复后可重新登录；两次操作均有审计记录。
- [ ] 缺权限、参数错误、网络失败、服务 5xx、空数据和保存成功状态均可理解并可恢复。

## 5. RBAC、管理员会话、step-up、邮件模板（P01-025 至 P01-028）

- [ ] `YL-M-037` 创建/修改角色和细粒度权限；低权限管理员无法越权保存。
- [ ] `YL-M-038` 管理员 Bearer 登录、会话查看和撤销可用；错误密码不创建会话。
- [ ] `YL-M-039` 高风险操作必须使用绑定当前会话、5 分钟有效且一次性消费的 step-up；复用/过期/跨会话 token 必须失败。
- [ ] `YL-M-040` 邮件模板保存递增版本并显示成功；旧版本并发保存返回版本冲突；投递记录可追溯。

## 6. 真实后台入口门禁

- [ ] `https://admin.orbexa.cc` 显示 YLVEN 管理后台并连接 P01 API；不得接受其他产品页面作为证据。
- [ ] `auth.orbexa.cc` DNS、TLS 和 `/health/ready` 真实可用；邮件服务与 Turnstile 使用项目所有者提供的 staging Secret。
- [ ] 首次管理员登录使用桌面私密文件中的一次性密码，登录后强制改密；密码不得进入 Git、CI、日志或聊天。
