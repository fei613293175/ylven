## 操作步骤与正确预期

- [ ] 校验交付目录 `校验文件_SHA256.txt`；正确预期：APK 和全部不可变文件哈希一致，任何失败都停止安装并重新获取交付物。
- [ ] 已安装 P00 1.0.0 时直接覆盖安装 P01 1.1.0；正确预期：安装成功、版本显示 1.1.0、应用数据不被安装过程清除。
- [ ] 冷启动 APK；正确预期：首屏为“登录 YLVEN”，不再显示 P00 四栏工程壳，旋转/前后台切换不崩溃。
- [ ] 在登录页输入非法邮箱并提交；正确预期：本地显示格式错误，修正后可恢复，不出现无限加载。
- [ ] 进入注册，输入邮箱、8 位以上字母数字密码和一致确认密码；正确预期：安全确认后进入六位验证码页。
- [ ] 输入错误验证码再输入页面显示的联调验证码；正确预期：错误请求失败且可恢复，正确验证码只消费一次并创建账户。
- [ ] 使用同一邮箱再次注册；正确预期：返回重复注册错误，不创建第二个用户，不泄漏密码或 token。
- [ ] 回到登录页获取验证码并完成登录；正确预期：进入“账户与设备”，能看到当前设备会话。
- [ ] 点击“刷新登录会话”；正确预期：刷新成功、旧 refresh token 在自动测试中不可复用，页面不中断。
- [ ] 在断网状态刷新或退出；正确预期：显示可恢复失败且本地会话不被误删；恢复网络后重试成功。
- [ ] 点击“退出全部设备”；正确预期：服务端撤销会话并回到登录页，旧 access token 无法继续查询设备。
- [ ] 连续触发超过限制的登录请求；正确预期：返回稳定限流错误，冷却后恢复，不因邮箱存在与否产生可枚举差异。
- [ ] 打开 `https://ai-admin.orbexa.cc`，使用私密交付文件中的账号登录；正确预期：出现 YLVEN ADMIN P01 页面并加载真实 API 数据。
- [ ] 使用错误后台密码后再使用正确密码；正确预期：错误请求不创建会话，正确请求进入用户列表且无密码摘要/token 字段。
- [ ] 进入用户列表并打开详情；正确预期：邮箱、状态和会话来自本次注册的真实用户，空数据和网络失败均有可恢复状态。
- [ ] 尝试禁用用户；正确预期：未 step-up 时拒绝并打开二次确认，确认后再次提交成功且用户已有会话立即失效。
- [ ] 使用同一个 step-up token 再次执行高风险操作；正确预期：复用失败，重新确认后才能恢复用户。
- [ ] 进入“角色”创建测试角色；正确预期：缺 step-up 时失败，确认后保存成功并在回读列表出现。
- [ ] 进入邮件、Turnstile、OTP 设置；正确预期：可编辑、保存、回读一致，原始 `secret` 字段被拒绝，只接受引用字段。
- [ ] 进入邮件模板修改主题并保存；正确预期：版本递增、投递记录可见，使用旧版本并发保存返回版本冲突。
- [ ] 点击后台“退出”；正确预期：浏览器 token 清除且服务端管理员会话撤销，返回登录页。
- [ ] 检查 APK 登录态持久化；正确预期：token 只存在 Android Keystore 加密密文中，杀进程重启可恢复，卸载后清除。
