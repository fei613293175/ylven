# 26 — YLVEN UI 设计系统与固定数值

## 1. 文档地位

本文件说明 `YL-DS-1.2.0`。机器权威文件是 `contracts/ui-design-tokens.yaml`。所有 Android、管理后台、开发者中心、公共网页和后续效果图均必须使用同一版本。效果图不是测量依据；数值合同才是测量依据。

## 2. Android 基准画布和响应式范围

- 基准逻辑画布：`360×800dp`；批量效果图：`1080×2400px @3x`。
- 不绘制手机外壳；保留状态栏和手势导航参考区。
- 必测宽度：`320dp`、`360dp`、`384dp`、`411dp`。
- 只支持竖屏作为首期商业版本；横屏不能崩溃，但不作为独立效果图基线。
- 使用 edge-to-edge；内容必须按系统 Insets 排布，禁止固定假状态栏高度侵入真实设备安全区。

深色模式数值已在 Token 中锁定。第一阶段可先实现浅色，但不得写死浅色色值；所有 Compose 和 Web 样式必须通过语义 Token，使深色模式无需重写页面。

## 5. 字体规则

- Android 使用系统 Roboto/Noto Sans CJK SC 回退，不在仓库分发字体文件。
- 正文固定 `16sp / 24sp`；不得为“塞下内容”降到 12sp。
- 页面标题固定 `24sp / 32sp / 700`；顶部栏短标题使用 `17sp / 24sp / 600`。
- 动态字体至少验证 1.0、1.15、1.3；不允许文本重叠或关键按钮离屏。
- 所有金额、UID、API Key、代码与 Token 数据使用适合的等宽或 tabular number 样式，但不得改变正文层级。

## 6. 圆角与阴影

- 业务卡片默认 16dp；输入框/主按钮 14dp；聊天气泡 18dp；输入器 24dp；Bottom Sheet 28dp。
- 禁止不同页面随意采用 8、12、20、24dp 作为“看起来更好”的卡片圆角。
- 普通卡片优先使用边框和 Surface 层级，不使用重阴影；浮层、Dialog、Sheet 才可使用 Level 2/3。

## 7. 访问性与触控

- 所有可点击元素最小触控区 48dp，即便可见图标只有 20/24dp。
- 文字对比度至少 4.5:1；大文字至少 3:1。
- 状态不能只靠颜色表达，必须有图标、文字或形状。
- TalkBack/键盘焦点顺序、内容描述和错误朗读属于完成条件。

## 8. 禁止事项

禁止在页面代码中硬编码新的色值、sp、dp、圆角、阴影、动画时长；禁止复制某个页面的私有样式到另一页；禁止根据效果图肉眼估算替代本合同；禁止为了匹配假数据而破坏真实长文本、空态、错误态和动态数据布局。
